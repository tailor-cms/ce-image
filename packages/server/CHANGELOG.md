# @tailor-cms/ce-image-server

## 3.0.0

### Major Changes

- Migrate to CEK 2.3.1. Packages are now ESM-only: CommonJS builds and the `main` / `require` entry points are removed, and the manifest and server packages emit `index.js` / `index.d.ts` instead of `index.mjs` / `index.d.mts`. The top toolbar is removed; image upload, URL import, replace and remove now happen in the element body through the `TailorFileInput` dropzone.

- Updated dependencies
  - @tailor-cms/ce-image-manifest@3.0.0
